## Current state

Philippines v12 retains the historical v10 energy system and Fisheries v2.3,
and adds the CLEWs Global-derived land, agriculture and water block. The
source case contains 172 technologies, 92 commodities and three constraints.

The derived `Philippines_v12_ENV_LAND` case adds an exact eight-mode
`ENV_LAND` terminal and land-balance equality. The separate active diagnostic
case adds an unforced three-mode `ENV_WATER` technology. Its Results Pivot
publishes the authoritative postprocessed water residual while preserving
the original solver CSVs.

Water residuals are diagnostics, not sustainable-yield estimates. The
groundwater/surface-water split can vary across cost-identical solver bases.
Read `documentation/KNOWN_LIMITATIONS.md` and
`documentation/ENVIRONMENTAL_ACCOUNTING.md` before interpreting results.

## Resume

From the repository root:

```bash
cd Philippines_v12_CLEWs_build
shasum -a 256 -c muio/SHA256SUMS
unzip -t muio/Philippines_v12_ENV_LAND_WATER_DIAGNOSTIC_v12.0.0_MUIO.zip
```

Import or unpack the diagnostic archive into MUIOGO, regenerate it through
the application, and solve through the normal MUIO chain. After every fresh
solve, run:

```bash
python scripts/publish_environmental_water_pivot.py
```

Use `--dry-run` first when only validation is intended. Do not copy
`data.txt`, `data_processed.txt`, LP files or result folders from another
laptop.
