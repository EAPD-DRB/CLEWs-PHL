# Philippines Fisheries v2.3 source package

This folder contains the authoritative documentation imported with the
Philippines v10 Fisheries v2.3 sector into Philippines v12.

Files copied unchanged from `WebAPP/DataStorage/Philippines_v10`:

- `FSH_CALIBRATION.md` — accounting boundary, data derivations, assumptions,
  parameter rationale, uncertainty, and v2.3 results;
- `FSH_GLOBAL_PARITY.md` — CLEWs Global parameter-semantics comparison and
  residual-stock evidence;
- `FSH_calibration_data.csv` — machine-readable parameter values and their
  source/assumption tags;
- `FSH_industry_carveout.csv` — annual direct useful-service deduction from
  aggregate Industry demand.

`DATA_SOURCE_REGISTER.md` indexes the named publications and review decisions
so Philippine officials can accept the current evidence or nominate better
national data. A raw-data copy is not required for that review.
