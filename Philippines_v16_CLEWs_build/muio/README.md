# Portable Philippines v16 MUIO case

`Philippines_v16_v16.0.0_MUIO.zip` contains the complete editable MUIO
parameter JSON, required view files, and local documentation for Philippines
v16. It is an identity-only successor to the validated v15 model: no model
parameter was changed.

Extract the `Philippines_v16` directory into
`MUIOGO/WebAPP/DataStorage/`, start MUIOGO, and regenerate the solver input
through the application before solving. Generated solver inputs and runtime
results are excluded from the archive.

Current archive:

- size: 23,242,325 bytes
- SHA-256: `b6163fbb97fd4ab1d1c441d77038ac034729aa6943ccc36f4da77529cae09e46`

`Philippines_v15_v15.0.0_MUIO.zip` is retained as predecessor evidence and is
also protected by Git tag `v15.0.0`.

Verify the archive before use:

```bash
sha256sum -c SHA256SUMS
```

The authoritative source ledger and validation evidence are in the parent
build package.
