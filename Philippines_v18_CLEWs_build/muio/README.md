# Portable Philippines v18 MUIO case

`Philippines_v18_v18.0.0_MUIO.zip` contains the complete editable v18 source,
view files, and local documentation. It retains the v17 land safeguards and
adds the source-traced v18 energy inputs without new technologies or
commodities.

Extract `Philippines_v18` into `MUIOGO/WebAPP/DataStorage/` and regenerate the
solver input before solving. Runtime results are excluded. Verify the archive
with `sha256sum -c SHA256SUMS`.

The v15-v17 archives are retained as predecessor evidence; v18 does not depend
on them to interpret its cumulative ledger.
