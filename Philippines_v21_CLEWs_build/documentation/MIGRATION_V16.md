# Philippines v16 migration record

Philippines v16 was created from the complete Philippines v15 canonical build
package on 2026-08-05. All provenance ledgers, retained evidence, model inputs,
documentation, diagnostics, and reproduction scripts were carried forward.

The only changes to the portable case are its case identity (`Philippines_v16`),
the matching `osy-casename`, local README text, and an empty result index. All
editable model-parameter JSON files are byte-for-byte inherited from v15.
Generated solver inputs and outputs are deliberately absent.

The predecessor is preserved by Git tag `v15.0.0` and by the retained v15
archive. The v16 archive is the documented current handoff package.
