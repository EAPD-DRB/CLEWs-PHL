# Portable Philippines v21 MUIO case

`Philippines_v21_v21.0.0_MUIO.zip` is the complete editable, result-free v21
source. Extract `Philippines_v21` under `MUIOGO/WebAPP/DataStorage/`, regenerate
solver input through MUIOGO, and run `BASE`.

The archive excludes `res/`, `data.txt`, `data_processed.txt`, LP files, and
solver results. Verify it with `shasum -a 256 -c SHA256SUMS` (or
`sha256sum -c SHA256SUMS`). Older archives are retained only as chronology;
the cumulative v21 ledger and evidence are complete without installing them.
