# Philippines_v19 documentation routing

This portable case carries the complete inherited v18 local documentation and
the v19 PM2.5 change manifest, factor register, implementation note, and
validation summary. The authoritative cumulative six-table ledger and full
retained source evidence are in the repository package
`Philippines_v19_CLEWs_build/data_sources/`.

The v19 change is limited to PM2.5 accounting for existing technologies. Read
`MODEL_FIXES_PM25_COVERAGE_2026-08-19.md`, then
`pm25_coverage_v19_2026-08-19.json` for exact source hashes and values, and
`pm25_coverage_v19_validation.json` for the bounded solve and result checks.

The portable archive is result-free. Regenerate solver inputs and results from
the editable JSON source before reviewing outputs.
