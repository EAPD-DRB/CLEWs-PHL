# Reproduction scripts

- `build_philippines_v30_yields_re_land.py`: rebuild v30 from canonical v29.
- `preflight_philippines_v30.py`: run static checks and generate/validate all scenario matrices without CBC.
- `run_philippines_v30.py`: run one reviewed scenario with a hard 300-second CBC deadline.
- `validate_philippines_v30.py`: validate solved land and crop identities.
