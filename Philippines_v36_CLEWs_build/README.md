# Philippines v36 CLEWs model

Philippines v36 is the user-accepted electricity and gas-generation history
successor to Philippines v33. The portable handoff preserves endogenous fuel
choice and does not impose historical generation, dispatch, or market-share
targets.

## Delivered model

- Portable editable case: `muio/Philippines_v36_v36.0.0_MUIO.zip`
- Case identity: `Philippines_v36`
- Runtime solver matrices, logs, results, and populated result views: excluded
